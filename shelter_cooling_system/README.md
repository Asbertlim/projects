Problem Statement
“How can we create a suitable environment for pets that require a cool habitat in a shelter?”

Problem: Many pets suffer (heatstroke, organ failure, death) due to scorching weather in tropical countries like Indonesia and Singapore. (e.g. pugs, guinea pigs, bulldogs)

Solution: A cooling system (fan) that turns on when the temperature reaches a certain amount.



Components

-> Arduino
-> Breadboard Small
-> TMP 36
-> NPN transistor
-> diode
-> resistor
-> DC motor
